## DocAnalyzer

### Repository

GitHub: https://github.com/Sufiyan0000/DocAnalyzer

### Live Application

https://analyze-doc.streamlit.app/

### Project Type

AI-Powered Document Assistant

### Status

Live

### Overview

DocAnalyzer is an AI-powered document assistant that allows users to upload PDF documents and ask questions about their content.

The application uses Retrieval-Augmented Generation (RAG), semantic search, vector embeddings, and Large Language Models to retrieve relevant information from uploaded documents and generate contextual responses.

### Core Features

- PDF document upload
- Document processing and ingestion
- Question answering over uploaded documents
- Retrieval-Augmented Generation
- Semantic search
- Vector-based document retrieval
- LLM-powered responses

### Technical Stack

- Python
- Streamlit
- LangChain
- ChromaDB
- RAG
- Embeddings
- Large Language Models

### Technical Highlights

- Document ingestion pipeline
- Text chunking and retrieval
- Vector embeddings
- Semantic search
- Retrieval-Augmented Generation
- LLM integration
- AI-powered question answering

### Challenges Addressed

- Converting unstructured PDF content into searchable information
- Retrieving relevant document context for user questions
- Connecting vector retrieval with LLM-generated responses
- Designing an intuitive interface for interacting with documents

### Outcome

DocAnalyzer provided practical experience in building an end-to-end Generative AI application and working with RAG pipelines, embeddings, vector databases, and LLM-powered responses.

### Repository

GitHub: https://github.com/Sufiyan0000/BookMyShow

### Project Type

Full-Stack Movie and Entertainment Booking Platform

### Status

Development Project

### Overview

BookMyShow is a full-stack web application inspired by modern movie and entertainment ticket-booking platforms.

The project includes movie discovery, theater and screen management, show scheduling, interactive seat selection, and booking workflows.

The application was built to gain practical experience in developing a complete frontend and backend system rather than only recreating a static interface.

### Core Features

- Movie discovery
- Movie detail pages
- Theater management
- Screen management
- Show scheduling
- Interactive seat selection
- Booking workflows
- User authentication
- Events and sports sections
- Responsive interface

### Technical Stack

- React
- TypeScript
- Tailwind CSS

Backend:

- Django
- Django REST Framework

Database:

- SQLite during development
- MySQL

### Technical Highlights

- REST API architecture
- Django REST Framework
- React-based frontend
- API-driven application
- Authentication
- Database relationships
- Dynamic seat availability
- Booking workflows
- Responsive UI

### Challenges Addressed

- Designing relationships between movies, theaters, screens, shows, seats, and bookings
- Managing seat availability for individual shows
